# EE6156 复习站

IE4756 / IE6156 / EE6156 **Computer Architecture Part 1** 的个人复习页面集合。全部是纯静态 HTML，用浏览器直接打开即可，不需要安装任何东西。

开启 GitHub Pages 后的在线地址：**https://pdsky.github.io/EE6156/**

## 内容

| 页面 | 用途 | 内容 |
|---|---|---|
| [芯片蓝图](chip-blueprint.html) | 系统学习 | 12 个模块覆盖讲义 1–6，含交互式 MIPS 指令编码器、总线时序动画和每模块自测题 |
| [习题册](tutorials.html) | 逐题精讲 | Tutorial 1–5 全部题目的完整推导 |
| [模拟卷](mock-paper.html) | 整卷练习 | 按近年真题结构出的原创题，答案默认折叠 |
| [性能与 I/O 练习](practice.html) | 专项练习 | 9 道 CPI / Amdahl / 磁盘 / DMA / 总线计算题 |
| [考前速查](cheatsheet.html) | 考前复习 | 公式、逐题结论、易错点、解题流程，可直接打印 |

推荐顺序：芯片蓝图 → 习题册 → 模拟卷 / 练习 → 考前速查。

## 本地使用

下载仓库后双击 `index.html` 即可。页面只从 Google Fonts 加载字体，离线时会自动退回系统字体，内容不受影响。
